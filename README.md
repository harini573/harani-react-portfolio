# Harani Vijaykumar — React Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local Vite URL shown in the terminal.

## Build for deployment
npm run build

The generated `dist` folder can be deployed to Vercel, Netlify, GitHub Pages (with suitable configuration), or another static host.

## Personalize
- Replace `your-email@example.com` in `src/main.jsx` with your email.
- Add real project GitHub/live-demo URLs to the project cards if available.
- Add a profile photo later if desired.
